# מערכת הערכת RAG - Evaluation System

מערכת להשוואה ובדיקת תצורות שונות של מערכת ה-RAG.

## 🚀 התחלה מהירה

הדרך הקלה ביותר:

```bash
cd tests/evaluation
python quick_start.py
```

זה יציג לך תפריט עם 3 אפשרויות:
1. **הרצת השוואה** - מריץ את כל השאלות דרך כל התצורות
2. **פתיחת ממשק דירוג** - דרג את התוצאות ידנית
3. **הצגת תוצאות אחרונות** - ראה מה קרה בהרצה האחרונה

## שלבי שימוש מפורטים

### 1. הכנת שאלות בדיקה

ערוך את הקובץ `test_questions.yaml` והוסף שאלות:

```yaml
questions:
  - id: 1
    question: "מה הדין של אכילת לחם בערב פסח?"
    category: "פסח"
    difficulty: "easy"
    notes: "שאלה ברורה עם מקורות מפורשים"
    expected_sources: "שולחן ערוך אורח חיים סימן תעא"
```

**טיפ:** התחל עם 3-5 שאלות ובדוק שהמערכת עובדת. אחר כך הוסף עוד.

### 2. הרצת ההשוואה

הרץ את כל השאלות דרך כל התצורות:

```bash
python run_comparison.py
```

זה יצור קובץ תוצאות ב-`results/comparison_results_YYYYMMDD_HHMMSS.json`

⏱️ זמן הרצה משוער: ~1-2 דקות לכל שאלה (תלוי במספר התצורות)

### 3. דירוג ידני של התוצאות

פתח את ממשק ה-UI לדירוג:

```bash
streamlit run evaluate_ui.py
```

הממשק יטען אוטומטית את הקובץ האחרון, או שתוכל להזין נתיב ספציפי.

**בממשק:**
- עבור על כל שאלה
- צפה בתשובות מכל תצורה
- דרג כל תשובה (1-5)
- הוסף הערות (אופציונלי)
- לחץ "שמור דירוגים"

### 4. ניתוח התוצאות

לאחר שדירגת לפחות כמה שאלות, הרץ ניתוח:

```bash
python analyze_results.py
```

זה יציג:
- ✅ איזו תצורה הכי טובה
- ❌ איזו תצורה הכי גרועה
- 📊 סטטיסטיקות מפורטות
- 💡 תובנות (האם BM25 עוזר? האם Reranker עוזר?)

הדירוגים נשמרים ב-`results/comparison_results_YYYYMMDD_HHMMSS_ratings.json`

## תצורות הנבדקות

המערכת בודקת את התצורות הבאות (ניתן לערוך ב-`run_comparison.py`):

1. **vector_only** - חיפוש וקטורי בלבד
2. **vector_bm25** - היברידי: וקטורי + BM25 (30/70)
3. **vector_bm25_reranker** - היברידי + reranker
4. **vector_only_top10** - וקטורי עם 10 תוצאות
5. **aggressive_bm25** - היברידי עם BM25 חזק יותר (50/50)

## סולם דירוג

- **1 ❌** - גרועה מאוד (טעויות הלכתיות)
- **2 ⚠️** - חלקית/לא מדויקת
- **3 ✅** - סבירה אבל חסרה
- **4 ⭐** - טובה ומדויקת
- **5 🌟** - מצוינת ומקיפה

## מטריקות מומלצות

בעת הדירוג, שים לב ל:

1. **דיוק הלכתי** - האם התשובה נכונה?
2. **מקוריות** - האם המקורות רלוונטיים?
3. **שלמות** - האם כל הדעות החשובות מוזכרות?
4. **ציטוטים** - האם הציטוטים מדויקים?
5. **בהירות** - האם התשובה ברורה ומובנת?

## ניתוח תוצאות

לאחר דירוג מספר שאלות, תוכל לראות בסיידבר:
- ממוצע דירוג לכל תצורה
- איזו תצורה עובדת הכי טוב

## הוספת תצורות נוספות

ערוך את הרשימה `CONFIGURATIONS` ב-`run_comparison.py`:

```python
CONFIGURATIONS.append(
    ConfigVariant(
        name="שם_תצורה",
        use_hybrid=True,
        use_reranker=False,
        top_k=7,
        bm25_weight=0.4,
        vector_weight=0.6,
    )
)
```

## שאלות נפוצות

**ש: כמה שאלות אני צריך כדי לקבל תוצאות משמעותיות?**  
ת: מינימום 5-10 שאלות. יותר = תוצאות אמינות יותר. מומלץ 20-30.

**ש: האם אני חייב לדרג את כל התצורות לכל שאלה?**  
ת: כן, כדי שהניתוח יהיה הוגן. אחרת לא תוכל להשוות.

**ש: מה עושים אם שתי תצורות נותנות תשובה זהה?**  
ת: דרג אותן באותו ציון. זה יכול לקרות, במיוחד אם ה-reranker לא משפיע על השאלה הזו.

**ש: איך אני יודע איזה top_k מתאים?**  
ת: בדוק! הוסף תצורות עם top_k=3, top_k=5, top_k=10 ותראה מה עובד הכי טוב.

**ש: האם אפשר לעצור באמצע ולהמשיך אחר כך?**  
ת: כן! הדירוגים נשמרים מיד. תוכל לדרג כמה שאלות, לסגור, ולהמשיך מאוחר יותר.

**ש: מה עם שאלות שאין להן תשובה במערכת?**  
ת: זה חשוב לבדוק! אם כל התצורות נותנות "לא נמצאו מקורות", זה אומר שהספר הרלוונטי לא הוכנס למערכת.

## טיפים לבדיקה יעילה

1. **התחל קטן** - 3-5 שאלות בהתחלה
2. **בחר שאלות מגוונות** - קל, בינוני, קשה
3. **כלול מחלוקות** - בדוק שהמערכת מציגה דעות שונות
4. **בדוק edge cases** - שאלות עם ניקוד, שאלות ארוכות, שאלות מודרניות
5. **תעד** - כתוב הערות על למה דירגת כך

## דוגמה לתהליך מלא

```bash
# 1. ערוך שאלות
notepad test_questions.yaml

# 2. הרץ השוואה
python run_comparison.py

# 3. דרג תוצאות
streamlit run evaluate_ui.py

# 4. נתח
python analyze_results.py

# 5. החלט איזו תצורה להשתמש בה!
```

## אז מה עכשיו?

לאחר שיש לך תוצאות ברורות, עדכן את `config.yaml` עם התצורה הטובה ביותר:

```yaml
retrieval:
  use_hybrid: true      # אם BM25 עזר
  use_reranker: true    # אם Reranker עזר
  top_k: 5              # הערך האופטימלי
  bm25_weight: 0.3      # המשקל האופטימלי
```
