# 🎯 מדריך שימוש מהיר - מערכת הערכת RAG

## מה בניתי לך?

מערכת מלאה להשוואת תצורות RAG שונות ודירוג ידני של התוצאות.

## 📦 מה כלול?

1. **test_questions.yaml** - 8 שאלות לדוגמה (תוכל להוסיף עוד)
2. **run_comparison.py** - מריץ כל שאלה דרך 5 תצורות שונות
3. **evaluate_ui.py** - ממשק Streamlit לדירוג התוצאות
4. **analyze_results.py** - ניתוח סטטיסטי של הדירוגים
5. **quick_start.py** - תפריט נוח להתחלה

## 🚀 איך משתמשים? (3 שלבים פשוטים)

### שלב 1: הרץ השוואה
```bash
cd tests/evaluation
python run_comparison.py
```

זה יריץ את כל 8 השאלות דרך 5 תצורות שונות:
- **vector_only** - רק חיפוש וקטורי
- **vector_bm25** - היברידי (30% BM25, 70% vector)
- **vector_bm25_reranker** - היברידי + reranker
- **vector_only_top10** - וקטורי עם 10 תוצאות
- **aggressive_bm25** - היברידי מאוזן (50/50)

⏱️ זמן: כ-8-16 דקות (תלוי במהירות המערכת)

### שלב 2: דרג את התוצאות
```bash
streamlit run evaluate_ui.py
```

הממשק יפתח בדפדפן. עבור על כל שאלה ודרג כל תצורה:
- ⭐ 1 = גרועה מאוד
- ⭐⭐ 2 = חלקית
- ⭐⭐⭐ 3 = סבירה
- ⭐⭐⭐⭐ 4 = טובה
- ⭐⭐⭐⭐⭐ 5 = מצוינת

💾 שמור דירוגים אחרי כל שאלה!

### שלב 3: ראה תוצאות
```bash
python analyze_results.py
```

זה יראה לך:
- 🏆 איזו תצורה הכי טובה
- 📊 ממוצעים ודירוגים
- 💡 תובנות (BM25 עוזר? Reranker עוזר?)

## 🎨 דרך חלופית (עם תפריט)

```bash
python quick_start.py
```

תקבל תפריט נוח עם 3 אפשרויות.

## 📝 דברים חשובים לזכור

1. **דרג בהגינות** - השווה תשובות אובייקטיבית
2. **בדוק מקורות** - האם המקורות באמת רלוונטיים?
3. **בדוק ציטוטים** - האם הציטוטים מדויקים?
4. **כתוב הערות** - למה דירגת כך? זה יעזור לך אחר כך

## 🎓 מה לעשות עם התוצאות?

אחרי שתדרג הכל ותראה איזו תצורה הכי טובה, עדכן את `config.yaml`:

```yaml
retrieval:
  use_hybrid: true       # אם BM25 שיפר
  use_reranker: true     # אם reranker שיפר  
  top_k: 5               # או 10 אם זה עבד יותר טוב
  bm25_weight: 0.3       # או 0.5 אם aggressive_bm25 ניצח
```

## 💡 טיפים

- **התחל קטן**: דרג 3-5 שאלות ראשונות, תראה שזה עובד
- **הוסף שאלות**: ערוך `test_questions.yaml` והוסף שאלות שחשובות לך
- **נסה וריאציות**: שנה את התצורות ב-`run_comparison.py`
- **שמור כל הזמן**: לחץ "שמור דירוגים" אחרי כל שאלה
